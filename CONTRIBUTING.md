# Contributing

Thank you for your interest in Argus.

Argus is maintained by JMV Metantel Private Limited and is offered under both the GNU Affero General Public License
v3.0 and a commercial license (see [`LICENSING.md`](LICENSING.md)). To keep both licenses possible, contributions of
code will be accepted only under a Contributor License Agreement with JMV Metantel Private Limited.

We are not yet accepting pull requests. Bug reports, questions and suggestions are welcome as GitHub issues.

To report a security vulnerability, do not open an issue; follow [`SECURITY.md`](SECURITY.md).
